## 玩法特色

- **自由烹饪：** 使用专用工具和电器，搅拌、研磨、烘焙、蒸制、冷冻、油炸、榨汁。
- **不止能做正餐：** 制作披萨、可定制冰淇淋、方便面、调味料，以及种类丰富的新食物。
- **搭建供电系统：** 发电并用电驱动厨房设备，也可以通过发酵生产沼气，用于供热和充当燃料。
- **让食材焕发生机：** 种植新作物，并在更多配方中使用受支持模组的食材。

## 安装说明

对于 **Fabric** 平台上的 **Minecraft 1.20.1**，请安装：

- Fabric Loader **0.19.5 或更高版本**
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [GeckoLib](https://modrinth.com/mod/geckolib)

以下模组为可选，但能提供实用的联动功能：

- [REI](https://modrinth.com/mod/rei) 或 [EMI](https://modrinth.com/mod/emi)：在游戏内浏览配方
- [Patchouli](https://modrinth.com/mod/patchouli)：游戏内指南书
- [Yet Another Config Lib](https://modrinth.com/mod/yacl) 和 [Mod Menu](https://modrinth.com/mod/modmenu)：模组配置界面

## 快速上手

- 按 **L** 打开进度界面，以查看相关提示。
- 安装 Patchouli 后，可用搅拌器和书来合成模组指南书。
- 使用 REI 或 EMI 查询配方和加工步骤。
